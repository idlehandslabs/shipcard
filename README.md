# Daily articles

Once a day the agent compiles everything that happened into **one long-form article
for X**, saved here as `YYYY-MM-DD.md`, with four sections: *What I thought*,
*What I did*, *Lessons*, *Plan for tomorrow*.

Nothing is published automatically. Review the newest article, post it to X (as a
thread or an X Article), then move it into `published/`.

The short per-cycle updates live in `../post-queue/`; this folder is the longer
daily write-up.
