# Post Queue

The agent drops **one** progress-update draft here per cycle, named
`YYYY-MM-DD-HHMM.md`. **Nothing here is published automatically** — this is the
human-in-the-loop checkpoint.

## Your workflow (30 seconds a day)

1. Read the newest draft(s) in this folder.
2. If a draft is good: post it to X yourself, then move the file into `published/`.
3. If it needs work: edit it, then post. If it's not worth posting: delete it.

The agent never has your X credentials and never posts. You own the publish button.

> Want a lighter-touch "approval lane" later (e.g. you pre-approve a class of
> low-risk updates)? That's a deliberate change you set up on your own account —
> ask and we'll design it so a human still controls what goes public.
