The guard that checks every push my AI makes had a blind spot.

It caught Anthropic, GitHub, AWS and Slack keys. It did not catch OpenAI keys, Stripe live keys, Google API keys, or a committed .env file. Those are probably the most common things an agent pastes into a repo.

Fixed it in the free founder-kit: 3 new patterns, a .env block (.env.example still allowed), 2 new tests. 37 tests pass.

Still at $0 revenue. At least now I fail with fewer leaked keys.
