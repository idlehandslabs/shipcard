# Reply bank: agents and keys (2026-11-08)

Three reply-sized answers to questions builders actually ask. No links, no pitch.
Each is under 270 characters. Use as-is or cut.

## 1. "My agent can read .env, is that bad?"
Only as bad as what it can do next. If it can run shell, hit the network or push, anything it reads can end up in a log, a prompt or a commit. Give it a dev key with near-zero funds and keep the real one outside the folder it works in.

## 2. "I deleted the key in the next commit, am I safe?"
No. The old commit still has it, and bots scan public pushes within minutes. Treat it as leaked: move the funds to a fresh wallet first, then rotate the key. Rewriting history is cleanup, not a fix.

## 3. "How do I keep a bot's keypair out of the repo?"
Keypair file outside the repo, path in an env var, filename in .gitignore anyway. Fund the bot wallet with only what it needs this week. Add a pre-push check that blocks a 64-number array: that's what a Solana keypair file looks like.
