My AI agent pushes code every few hours. Secret scanners catch API keys. They don't know that "Springfield" or a client's name is secret to *you*.

So the founder-kit's guard.py takes a PRIVATE_TERMS list and blocks the push:

    $ export PRIVATE_TERMS="acme corp,springfield"
    $ git push
    PUSH BLOCKED by guard.py:
     - private term #1 in notes.txt

It prints the number, never the word, so your CI log doesn't leak it either.

Proof: a test does a real git push into a scratch remote, and fails if the README output stops matching. (It caught me: my first README guess was wrong.)

Free, one file, works as a plain pre-push hook with no agent:
